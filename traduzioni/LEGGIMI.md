# Traduzioni da far controllare

Un file per lingua (de, fr, es, ro, sq, ar, zh). Ogni riga: `chiave<TAB>testo tradotto`.
Sono i testi aggiunti nella v0.44; l'originale italiano è in `i18n.js` con la stessa chiave.
Chi conosce la lingua può correggere il file e rimandarlo: le correzioni vanno poi riportate in fondo a `i18n.js` (blocchi `TR('xx', {...})`).
I segnaposto tra graffe, per esempio `{n}`, devono restare identici.
